# chore-retire-obsolete-record

## Goal

按用户要求，**移除一份已废弃的"暂缓决策"档案及其任务记录**，避免未来（人或 AI）把它当成待办事项拾起并误做维护。不涉及任何代码、配置或运行环境变更。

## 移除范围

| 对象 | 处置 |
|---|---|
| 归档任务目录 `archive/2026-09/<该任务>` | 删除（`git rm -r`） |
| journal 中对应的会话条目 | 删除整段（含其在索引/表格中的引用） |
| `.trellis/tasks/index.md` 等索引引用 | 删除相关行 |
| 本次移除动作本身的记录 | 保留一份**中性、无细节**的说明（便于审计"为何少了一条记录"） |

## Constraints

- 不改任何代码/配置/运行环境
- 不触碰其他历史任务（包括已脱敏的生产机排查记录）
- **已知局限**：该档案此前已推送到远端仓库，git 历史中仍可检索到；如需彻底清除需重写历史或转私有（默认不做，如需要由用户另行决定）

## Acceptance Criteria

- [ ] 归档任务目录删除
- [ ] journal 对应会话条目与引用删除
- [ ] 索引引用清理
- [ ] 全仓 `grep` 复核：除本次移除说明外无残留引用
- [ ] 门禁 + 归档 + journal + push
