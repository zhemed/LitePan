# generate-bulk-5000-512k-testfiles

## Goal

在映射目录生成 **5000 个 512KiB** 独立随机测试文件，供用户验证大批量上传。**只生成文件，不发起上传**（用户自行在面板操作）。

## Requirements

1. 数量与大小：**5000 个文件 × 524288 字节（512KiB）= 2.5GiB**
2. 内容**互不相同**（独立随机，避免天翼秒传把测试变成"秒传演练"）
3. 落位：`/root/LitePan/mounts/LitePan-123/bulk-5000-512k/`（容器视角 `/app/mounts/LitePan-123/bulk-5000-512k`）
4. 命名：`bulk5k_0000.bin` ~ `bulk5k_4999.bin`
5. 生成方式：单次 `urandom` 流 + `split`（避免 5000 次子进程）
6. 校验：文件数 = 5000、单文件 = 524288 B、**全量 MD5 去重 = 5000**、磁盘余量充足
7. 记录容器路径供面板使用 + 预期吞吐基准

## Constraints

- 不自动上传；不新增/修改任何应用代码（无需发布版本）
- 磁盘余量充足（当前 227G 可用，占用 2.5G）

## Acceptance Criteria

- [x] 5000 个文件就位（bulk5k_0000~4999.bin，路径符合约定）
- [x] 三重校验通过（5000 个 / 合计 2621440000 B / MD5 5000 唯一）
- [x] 容器内实测可见 5000 项、单文件 524288 B
- [x] 容器路径 /app/mounts/LitePan-123/bulk-5000-512k + 预估 100-150 分钟基准已记录
- [x] 门禁 + 归档 + journal + push
