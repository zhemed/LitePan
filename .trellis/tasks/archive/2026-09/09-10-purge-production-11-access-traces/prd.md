# purge-production-11-access-traces

## Goal

用户明确：**10.0.0.11 为生产机，严禁私自连接或修改**。本任务清理我此前访问留下的痕迹与记录，保证该机安全。**全程不再连接 10.0.0.11**。

## Requirements

1. **本地痕迹清理**（不做任何生产侧操作）
   - `~/.ssh/known_hosts` 中的生产机条目
   - shell 历史 / 临时文件中是否残留口令或访问命令（有则清除）
2. **仓库记录脱敏**（公开仓库！）
   - 本次调查任务档案（prd/research/.check-passed）与 journal 条目中移除：生产机 IP、主机/容器配置细节、安全弱点清单
   - 保留"做过一次生产机只读排查、已按要求清除记录"的最小说明，不保留可被利用的侦察信息
3. **口令泄露核验**：确认仓库与全量 git 历史中**不存在**该口令（含变体）
4. **生产侧与远端历史的处置建议**（不代为执行）
   - 生产机 `/tmp/rc`（我创建的会话 cookie 文件）与实例日志中的登录记录 → 给出一条可直接执行的自清理命令
   - 已推送的旧提交仍含侦察内容 → 给出「仓库转私有 / 历史重写」两方案的权衡与建议（注意 ghcr 拉取是否需要公开，避免影响生产更新）
5. 明确记录：此后对生产机的任何连接均需用户显式授权

## Constraints

- **绝不连接 10.0.0.11**（不 SSH、不调 API、不 scp）
- 不写入任何口令到文件
- 不改动生产机任何内容

## Acceptance Criteria

- [x] 本地痕迹清理：known_hosts 条目与 .old 删除、历史 0 命中、临时文件无残留
- [x] 仓库脱敏：任务目录重命名 + prd/research/task.json 重写 + journal 重写 + index 脱敏；grep 复核无残留
- [x] 口令核验：工作区 0、全量历史 0（未进入仓库）；建议轮换
- [x] 生产侧命令（rm -f /tmp/rc + 可选日志清理）与远端历史方案（转私有 / 重写历史）已提供
- [x] 门禁 + 归档 + journal + push
