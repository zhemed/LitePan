# PRD：澄清并回答"其它工具"是否会踩 115 直链 UA 绑定

## Goal

用户澄清：上一轮我把问题理解成"LitePan 的其它驱动"，他说不是，**问的是"其它的工具"**。
本轮目标：① 用一句话给出**通用判据**（不区分具体软件）；② 用交互组件确认他具体指哪一类，
以便下一轮给出针对性结论（含 Alist 软件的直链/代理配置）。

## Background

- 已实测的失效机理：**115 CDN 直链签名只绑定"取链时的 User-Agent"**（与 IP 无关）。
  任何"用身份 A 取链、用身份 B 下载"的组合都会得到 `403 invalid signature`；
  而该 403 带 `application/zip + attachment`，手机端就显示 `ERR_INVALID_RESPONSE`。
- 我方修复（v0.0.50）的两跳握手正是让"下载方用自己的 UA 重新取链"。

## Requirements

- R1：给出**通用判据**："取链方与下载方是否同一身份"→ 同一则无此问题，不同则必然复现；解法只有两条
  （让下载方自己取链，或让服务端代下/中转）。
- R2：按最可能的解读给出速答（第三方软件如 Alist/Emby、LitePan 的辅助工具菜单、其它挂载方式）。
- R3：**用 `ask_user_question` 确认**他指的是哪一类，避免再次答偏。
- R4：只读；不改代码/配置；不访问外部主机。

## Acceptance Criteria

- [x] 通用判据已给出
- [x] 已用交互组件确认用户所指类别
- [x] 零越界（只读）
- [x] 任务归档 + journal
